# DV01 接近零，为什么组合仍可能亏损？

这份历史案例使用 **2025-12-31** 的拟合零息曲线，研究利率风险的形状。
数据是美联储工作人员的历史曲线估计，经已记录的公开镜像取得；
债券和头寸是假设案例，既不是实盘持仓，也不是当日市场报价。

## 先看最有解释力的反例

持有面值 **250 万美元的 10 年期债券**，并卖空约 **1,038.09 万美元的 2 年期债券**，
可以把这个模型组合的平行 DV01 调整到接近零。两条腿的总面值敞口约为 1,288.09 万美元。

| 变化 | 一阶线性估计 P&L | 完整重估 P&L |
| --- | ---: | ---: |
| 所有期限同时上升 50bp | 约 0 美元 | +1,834.40 美元 |
| 2 年下降 25bp、10 年上升 25bp | -94,335.23 美元 | **-93,918.70 美元** |

原因并不矛盾：平行 DV01 只压缩了“整条曲线同幅移动”这一维风险。
长短债对不同期限变化的敏感度仍有差异；有限幅度变化还会留下凸性影响。
该对冲例子不计融资、信用、流动性和持有时间变化，不能解释成低杠杆或无风险交易。

## 再看线性近似的误差

另一组独立的多头阶梯组合，分别持有面值 250 万美元的 2/5/10/30 年债券，
票息年化 4%、半年付息。平行上升 50bp 时：

| 方法 | 组合 P&L |
| --- | ---: |
| 一阶 DV01 近似 | -357,210.08 美元 |
| 每笔现金流完整重估 | -344,453.93 美元 |
| 完整重估减线性结果 | **+12,756.15 美元** |

打开[交互实验室](https://dev-belly.github.io/StressAtlas/curveshift/)，
改变四个关键期限的利率，直接看价格和误差如何变化。
“这条曲线变陡了多少”和“组合有没有平行久期风险”是两个不同的问题。

## 用真实历史变化扩展研究

冻结数据有 **2,499 条 2016—2025 年曲线估计**。
取估值日前最近 756 次连续可用观测之间的曲线变化，施加到固定的当前现金流上：

- 99% 历史情景 VaR：约 **97,552.17 美元**。
- 99% ES：约 **106,793.94 美元**。
- 300 次、每块 20 个观测的移动块重采样，ES 的 95% 重采样区间约为 **95,502.76—115,585.85 美元**。

这里不滚动债券期限，也不计算历史持仓收益，因此不是组合回测或 VaR 预测覆盖检验。
所有 756 个损失情景均可下载，分位点边界采用精确尾部概率质量处理。

PCA 只用 **2016—2024 年**的八期限利率变化拟合，再检查 **2025 年**。
前三个方向在训练集解释约 **97.87%** 的方差，在留出年的重构能量约为 **98.42%**。
它用于观察曲线变化的多维结构，不表示预测能力；原始历史数据本身仍可能有后续修订。

## 哪些工作是你能展示的

原始 NSS 数学模型来自 luphord 的 MIT 开源实现，QuantLib 提供金融基础组件。
本项目新增了真实曲线数据适配、假设债券估值、关键期限风险与凸性、
对冲反例、历史完整重估、按时间划分的 PCA、场景 API 和浏览器到 Python 的重放。

面试时可以围绕四个问题展开：为什么不能把平价收益率直接当作零息贴现率；
为什么 DV01 中性不代表曲线中性；为什么线性近似会偏离完整重估；
为什么固定现金流的历史情景分析不等于真实组合回测。
