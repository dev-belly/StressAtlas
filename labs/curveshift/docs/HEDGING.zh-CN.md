# CurveShift：风险识别之后，怎样配置有限的对冲仓位？

**固定 1,000 万美元面值的 7 年期模型债券，给定对冲面值预算，自动求出对冲交易，并查看下一年的情景风险。**

## 实验与时间隔离

| 项目 | 固定口径 |
| --- | --- |
| 目标仓位 | 1,000 万美元面值、7 年期、3.5% 年票息的假设债券；不允许卖出目标仓位 |
| 可交易对冲工具 | 2 / 5 / 10 / 30 年期、4% 年票息假设债券；允许有符号的买卖仓位 |
| 现金流与基础曲线 | 固定在 2024-12-31；沿用 QuantLib 半年付息与 NSS 连续复利贴现 |
| 拟合样本 | 504 个相邻可用观察的变化，结束日期 2022-12-27 至 2024-12-31 |
| 检验样本 | 249 个变化，结束日期 2025-01-02 至 2025-12-31；固定权重，不重新拟合 |
| 总面值预算 | 0 / 200 / 400 / 600 / 800 万美元；每个预算分别求解 |
| 单券限制 | 每个期限的对冲总面值不超过 300 万美元 |
| 成本假设 | 一次建仓按成交面值收取 2bp；不代表市场实际报价 |
| 优化目标 | 拟合期 97.5% ES + 一次建仓成本 |

预算网格、600 万美元默认展示值、置信度与成本都是演示参数。没有通过 2025 年检验结果选择最优预算。
每个历史变化都在每笔现金流的实际期限上计算：把两条历史 NSS 曲线的差加到固定基础曲线上，重新贴现。
历史损失对有符号面值是线性的；这里的线性规划不等于用 DV01 线性近似债券价格。

## 线性规划

记目标债券在情景 $`s`$ 下的美元损失为 $`a_s`$，每 100 万美元面值对冲工具的损失向量为 $`B_s`$。
对冲数量 $`h=h^+-h^-`$ 的单位是“100 万美元面值”。引入阈值 $`t`$ 与非负尾部超额变量 $`u_s`$：

```math
\min_{h^+,h^-,t,u}\quad
t+\frac{1}{(1-\alpha)n}\sum_s u_s
+200\sum_j(h_j^++h_j^-)
```

```math
u_s\ge a_s+B_s(h^+-h^-)-t,\quad u_s\ge0,
```

```math
\sum_j(h_j^++h_j^-)\le \frac{G}{10^6},\quad
h_j^++h_j^-\le3,\quad h_j^+,h_j^-\ge0.
```

其中 $`\alpha=0.975`$、$`n=504`$、$`G`$ 是美元面值预算；2bp 对 100 万美元面值的建仓成本为 200 美元。
实际求解将美元损失除以 1,000 改善量纲，并使用 SciPy CSR 稀疏矩阵与 HiGHS dual simplex。
模型有 **513 个变量、509 个约束、5,056 个非零系数**。

求解后独立重算经验 ES 的精确尾部概率质量、面值约束、成本与目标值，并检查原始—对偶目标差。
不能把简单的“超过 VaR 的样本平均”替代精确尾部质量；本例 504×2.5%=12.6 个样本，边界样本需要部分权重。

方法沿用 [Rockafellar 与 Uryasev 的 CVaR 优化表述](https://sites.math.washington.edu/~rtr/papers/rtr179-CVaR1.pdf)。
数值接口见 [SciPy 1.17.0 / HiGHS 文档](https://docs.scipy.org/doc/scipy-1.17.0/reference/optimize.linprog-highs.html)。
这是既有方法的债券应用，原始算法归属保留给作者。

## 保存的结果

| 对冲面值预算 / 美元 | 拟合 ES + 建仓成本 / 美元 | 2025 情景 ES / 美元 | 一次建仓成本 / 美元 |
| ---: | ---: | ---: | ---: |
| 0 | 93,791.32 | 71,789.20 | 0.00 |
| 2,000,000 | 65,801.34 | 56,929.61 | 400.00 |
| 4,000,000 | 45,946.07 | 40,720.43 | 800.00 |
| 6,000,000 | 30,369.72 | 29,039.70 | 1,200.00 |
| 8,000,000 | 19,781.17 | 20,617.96 | 1,600.00 |

默认 600 万美元预算的交易是：2Y 不交易，卖出 5Y 面值 **1,208,733.05** 美元、10Y **3,000,000.00** 美元、
30Y **1,791,266.95** 美元。2025 情景 ES 下降约 **59.5%**；加上一次成本后的情景 ES 为 **30,239.70** 美元。
拟合目标随预算增加应不变或下降；检验期 ES 不保证具有这种性质。

页面保留负的关键期限 DV01，允许用户查看局部曲线扭曲对原仓位和对冲后仓位的影响。
对冲降低历史分布的尾部风险，不保证每个自定义冲击都改善。模型价值下的卖出所得在页面显示，但没有计入融资收益。

## 复现

从 StressAtlas 仓库根目录运行，命令同样适用于 Windows PowerShell：

```bash
uv sync --project labs/curveshift --locked --extra dev --extra api
uv run --project labs/curveshift --locked curveshift hedge --budget-usd 6000000 --cost-bp 2
uv run --project labs/curveshift --locked curveshift hedge-report --out output/hedge
uv run --project labs/curveshift --locked curveshift hedge-verify output/hedge
uv run --project labs/curveshift --locked pytest labs/curveshift/tests -q
```

输出目录必须不存在或为空。HTML 自包含；可下载全部研究 JSON、预算比较 CSV、全部检验期情景损失和当前选择的交易。
地址中的预算与四个冲击可恢复同一实验。API 的 `POST /hedge` 支持 0–1,000 万美元预算、0–50bp 成本，
可以附带源数据 SHA-256；拒绝未知字段、布尔/字符串伪装的数值和不同源指纹。

`hedge-verify` 检查成员文件集合、哈希、源数据指纹，再重新拟合、重新计算检验结果，最后校对 CSV 与 HTML。
美元值允许绝对 1e-5、相对 1e-9 的数值差异；求解器诊断允许绝对 1e-3 的末位差异。
测试包含手算最优解、分数尾部、过高交易成本下不交易、独立 QuantLib 重估、修改 2025 数据不改变拟合交易、
以及篡改结果后重算哈希仍无法通过核验的反例。已安装 wheel 在仓库外生成并核验两种报告；跨平台 CI 重放保存结果。

## 适用范围与局限

2025 变化同样施加到固定 2024 年底的现金流与曲线上，不按日滚动期限，也没有实际成交、利息收入与持仓收益序列。
因此是留出年份的情景分布检验，不能称为收益回测或实盘盈利。公开曲线是拟合估计且历史版本可能修订，
时间隔离不能证明数据当时的发布可得性。没有券源、保证金、抵押、融资、信用、流动性、冲击成本或监管资本模型；
单一检验年份也不建立尾部估计的统计稳定性。
